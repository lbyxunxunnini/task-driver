# 修复循环必须改变策略

## 场景

一个可修复问题在第一次调整后仍以相同原因失败。

## 预期行为

1. 模型记录本轮失败原因、采用的策略和复验证据。
2. 下一次修复改变实施策略或修复内容，不重复上一轮命令或改法。
3. 如果只剩相同处理方式，模型停止机械重试并返回计划检查；没有可靠替代方案时标记受阻。
4. 最多 3 次是上限，不是必须用满的次数。

## 失败表现

- 为凑满三次重复完全相同的操作。
- 没有记录策略变化就声称完成修复循环。
