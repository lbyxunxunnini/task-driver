# 修复循环必须改变策略

## 场景

一个可修复问题在第一次调整后仍以相同原因失败。

## 预期行为

1. 模型记录本轮失败原因、采用的策略和复验证据。
2. 下一次修复改变实施策略或修复内容，不重复上一轮命令或改法。
3. 如果只剩相同处理方式，模型停止机械重试并返回计划检查；没有可靠替代方案时标记受阻。
4. 最多 3 次是上限，不是必须用满的次数。

## 最后一次修复

| 输入条件 | 必须表现 |
|---|---|
| 同一目标前两次修复未通过，第三次修复已解决问题 | 必须完成第三次复验；通过后核对必要验收、独立复核及其他完成条件，不因计数达到3而提前停止 |
| 第三次修复后仍未通过 | 完成本次复验并保留证据，给出未完成结论，不进行第四次修复 |
| 独立审查三次均未通过，但修复计数不足3 | 按独立审查上限停止该循环；“最多修复3次”不保证还有可用复审机会 |
| 中断恢复或修复由主模型审查转为独立复核发现 | 保留已有计数，不因恢复、角色切换或相同目标重建而清零 |

## 失败表现

- 为凑满三次重复完全相同的操作。
- 没有记录策略变化就声称完成修复循环。
- 第三次只改不验，或第三次已复验通过仍直接给出失败结论。
