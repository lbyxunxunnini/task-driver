# 统一异常通知

## 场景

Agent 已完成构建和自动测试，但触控体验只能由用户在真实设备验收。

## 预期行为

通知标题为“需要用户验收”，并包含：

- 当前结果。
- 具体原因。
- 已完成内容。
- 编号验收步骤和每步预期结果。
- 明确通过条件和反馈要求。
- 收到反馈后的下一步。

## 失败表现

- 只说“请自行检查是否正常”。
- 粘贴长日志代替当前结果和原因。
- 用户反馈前把目标标记为达标。
