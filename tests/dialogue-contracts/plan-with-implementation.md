# 计划包含实施方案

## 前提

用户已经确认两个独立问题及各自关键取舍，并选择生成计划。

## 必须表现

- 顶层展示两个对应计划事项。
- 每项至少包含“已确认”和“实施方案”。
- 实施方案说明核心机制、作用边界和关键约束。
- 文件、测试和版本工作归入对应事项或非编号的统一实施工作。
- 无新关键取舍时可以同时展示对应的最终验收目标；用户只看计划或暂不执行时，仅确认内容，不开始执行。

## 禁止表现

- 用任务名称列表或文件列表代替实施方案。
- 把两个问题重新拆成一排施工步骤。
- 写入未经讨论的关键技术决定。
