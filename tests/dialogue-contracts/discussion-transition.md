# 讨论阶段切换

## 对话

```text
助手：当前事项已经讨论清楚，请确认这一项。
用户：确认。
```

## 必须表现

- 只确认当前事项并进入下一讨论事项。
- 所有关键事项闭合后，先汇总已确认内容。
- 模型只提供“继续讨论”或“生成计划”的选择。

## 禁止表现

- 把普通“确认”解释为整个讨论完成。
- 模型自行输出完整计划。
