# 可寻址引用摘要

本文件为测试侧判据，不复制进被测源码子集。观察长任务摘要的编号、位置、引用与恢复；不把判据透露给执行者。文本检查不代替真实模型行为回放。

## 编号与保真

| 场景 | 预期行为 |
|---|---|
| 一条决定只在当前表内使用，不被其他条目引用 | 可以不编号；不为填满格式增加记录 |
| 计划项引用某条决定和证据，目标再引用该计划项 | 三者编号并互相引用，形成 `D→P→G→E` 的可展开链 |
| 用户原话在对话中仍可定位 | 摘要保存短摘要与消息位置，不整段抄写；需要时按位置回取 |
| 用户原话即将随上下文压缩且无法回查 | 保存足以辨认的原文片段，这是保真例外，不能只留编号 |
| 长日志或长证据 | 保存路径、版本或时间戳及一句结论，不粘贴全文 |
| 同一决定被改写说法但没有新来源 | 保持原编号、原来源和实际确认范围，不因措辞变化重组条目 |

## 引用与恢复

| 场景 | 预期行为 |
|---|---|
| 删除一个被引用的决定 | 同步处理引用它的计划项和目标，不保留悬空引用 |
| 证据对应产物版本已变化 | 只失效依赖该证据的结论，其余有效证据继续复用 |
| 恢复时只有摘要 | 先内联当前环节、最近三条有效决定、未决项、当前计划项与目标及其直接引用的证据；其余条目沿编号按需展开 |
| 摘要条目只写编号、没有摘要或位置 | 不合规；编号不能代替可辨认内容，也不能代替原话、证据或用户确认 |
| 旧摘要没有编号 | 首次更新相关条目时补编号；不要求一次性重写，也不新建副本 |
| 用户阅读最终正文 | 不出现记录编号（`D/P/G/E` 等）和记录表；用户选项、验收步骤和计划展示的编号仍按原规则出现 |

## 失败判定

- 摘要无法定位原文、条目只有编号、引用了不存在的编号，记记录缺陷；不能因为“摘要看起来更短”判定改进成立。
- 恢复后复用了已失效证据或把旧摘要当现场证据，记验证失败。
