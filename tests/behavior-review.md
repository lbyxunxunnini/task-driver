# 行为评测与五维验收

这是开发验证说明，不是 task-driver 的新用户阶段或运行依赖。行为规则以 `SKILL.md` 为准。

## 固定比较口径

- 基线：`4f9addf` 加此前已确认的“审查通过后完成任务、澄清期摘要例外”修复。整改前已保存完整快照；不是未经修复的旧提交。
- 评分：沿用本轮九维等权口径，原分数合计 34/45。争取至少 41/45；不能修改权重、标准或通过条件来凑分。
- 五维各自判断，不平均抵消。数值评分须引用具体证据；没有证据时不能默认为不退步。
- 同一输入、模型、宿主版本及工具范围进行前后对照。一次状态快照不代表长会话或所有任务的稳定成功率。
- 所有 14 份对话契约均包含一个 `behavior-eval` JSON 注释，仅编码输入和关键断言；文字契约仍说明完整含义。执行者只读取输入，不读取预期断言。

## 五维硬性门槛

| 维度 | 固定要求 | 比较证据 |
|---|---|---|
| Trust | 局部确认不扩大、目标不改写、不提前完成、限制如实说明 | 授权、恢复、用户验收场景的回复及工具记录；协议差异人工核对 |
| Reliability | 原已通过关键场景不回退，失败有退出，目标不重复创建 | 成对场景、状态查询/写入结果、修复与受阻分支；未覆盖分支单列 |
| Adaptability | 原任务类型继续可用；工具缺失可降级；评分和审查不强制 | 五类场景指南、无目标工具场景、审查开关及普通任务路径核对 |
| Convention | 主协议唯一真源，术语与引用一致，遵守本地规则 | 契约检查、链接检查、版本检查及差异核对 |
| Effectiveness | 结果不降低；普通任务不新增确认、重复提问和运行负担 | 成对回复人工复核、主协议实际输入量、工具调用、费用及耗时 |

以上只对本轮明确范围和测试样本给结论；不能把字符检查或少量模型回答包装成普遍保证。已有样本失败须保留并解释；工具故障、测试回合不足和协议失败分别记录。

## 复杂度预算

- 用户阶段、普通任务必要确认、默认记录文件：相对基线不增加。
- 必需服务、账号、第三方 Python/Node 包：不新增。日常执行无需本脚本或 Claude CLI。
- 开放任务品质评价按需使用，在原有目标确认中确定参考和标准；普通任务不填评分表。
- 复用既有摘要，不新增修复日志、交接包或审查状态文件。
- 不以行数验收。比较实际加载的主协议字符/模型输入；另外列出所有文档体积，避免靠搬文字掩盖负担。
- 模型回答有随机波动，耗时和费用只作本批样本对照，不给无样本支撑的稳定概率或统计显著性结论。

## 三层证据

1. 文本及引用检查：证明规则、契约和链接存在，不能证明模型遵守。
2. 真实模型、受控状态快照：CLI 实际请求本机已有路由配置的模型，在临时目录使用受限 MCP 工具。可以观察可见回复、调用、文件结果；这不等于生产任务工具验证。
3. 真实宿主 UI/自动触发、完整多轮会话及真实业务 Skill：本脚本不模拟这些，必须单列验证状态。

`serve` 只提供临时目录写入及合成任务查询/更新，不提供命令、网络或真实账户操作。拒绝越出临时目录的写入，拒绝非当前用例授权路径，记录每次调用。TaskList/TaskUpdate 是合成任务，不宣称修改真实宿主任务。

## 有界模型回放

真实调用前须明确模型、用例数量、重复次数及费用上限。`check`、`compare`、`recheck` 和单元检查不调用模型。

```bash
python3 scripts/behavior_checks.py run --source /path/to/baseline \
  --output .task-driver/evals/baseline --ledger .task-driver/evals/budget.json
python3 scripts/behavior_checks.py run --model SAME_REPORTED_MODEL \
  --output .task-driver/evals/candidate --ledger .task-driver/evals/budget.json
python3 scripts/behavior_checks.py compare \
  .task-driver/evals/baseline/report.json .task-driver/evals/candidate/report.json
```

- 共用预算记录，启动前保守预留次数和金额；失败也保留记录，不机械重试。
- 本轮授权最多 36 次模型调用和 US$5，脚本默认预留上限 US$4，单次 US$0.12，另留余量。CLI 费用是客户端估算，不等于供应商账单。
- 不自动改变供应商或选择新模型。精简模式只将本机现有认证/路由环境传给子进程，不改设置、不打印或写入凭据。
- 原始回复、工具记录和机器报告保存在已忽略的 `.task-driver/evals/`。不提交密钥、原始会话或本机配置。
- `--max-turns` 是宿主循环上限，错误结果中的循环数不一定等于有效模型请求数；用消息 ID 去重核对实际响应，保守预留仍计入调用预算。
- CLI 故障、未知费用或模型切换时停止，不自动换路由重试。

若判定器错误，可用 `recheck 原报告 新报告` 只重算已有回复的文本断言；原始记录不改，保留原定义哈希和修正原因。不得借此更改业务验收条件或删除工具/文件失败。

## 复评与停止

先通过五维门槛和复杂度预算，再按原九维评分。缺少长会话、品质或隔离审查实际证据时说明限制，不靠宣称“全面完备”补分。若同一验收项修复最多三次仍失败，或已无可靠改法，保留状态和证据，停止无限整改。
