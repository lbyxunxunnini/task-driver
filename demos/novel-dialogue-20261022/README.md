## 核验与取证

- [最终验收、目标完成和哈希](run-verification.json)：四个原目标均在实际阅读验收之后complete。
- [字数、章节与重复段落辅助筛查](artifact-verification.json)：筛查不能替代文学审核。
- [冻结协议的14个文件哈希](protocol-verification.json)：测试期间协议未改；基线提交9cb92c56a73c2b57e681d3d35d8ae38567aac477。
- first-delivered/与accepted-revisions/保留必要的首稿和修订对比及完成回执；run-verification.json中的相对证据路径均包含在本demo。
- [暂停和恢复事件](lifecycle-events.jsonl)、stopped-snapshot/和process-evidence/用于说明当时状态，不代表仍在执行。

## 如何复查

直接打开报告、问答和小说即可阅读，无需安装运行环境。可以按artifact-verification.json重算SHA256，核对最终小说与被审核版本一致。需要复跑时，从统一请求“tdr- 我想写一篇约两万字的中文小说，希望围绕一个主题。”开始，由被测代理自行加载Skill、提问和推荐；评审侧的15类覆盖表不要提前交给被测者。重新运行会受模型、宿主能力和真实回复影响，不保证问题或小说相同。

本demo是可阅读证据与产物归档，不包含自动调度器；完整原始日志与本机控制脚本仍在忽略目录。未纳入先前设置错误的自由创作轮，未新增协议、版本或发布动作。
